# QA Python Tasks - Selenium Fundamentals

## What is this?
This repository contains practical web automation exercises with Selenium and Python, designed to master the fundamentals of web element interaction.

## Product / Functionality under test
- Practice web page for Selenium exercises
- Basic web elements: input fields, buttons, texts, navigation

## Objective
Practice and demonstrate mastery of fundamental Selenium commands for automating web element interactions.

## Scope
**Included:**
- Element location (find_element)
- Basic interactions: click, typing in inputs, scroll
- Text extraction from elements
- Page opening and closing
- Progressive practical exercises

**Not included:**
- Page Object Model (POM)
- Advanced assertions
- Complete testing framework

## Artifacts in this folder
| File | Description | Skill demonstrated |
|---------|-------------|---------------------|
| `find_element_exercise_1.py` | First location exercise | Selenium find_element, basic selectors |
| `find_element_exercise_2.py` | Second location exercise | CSS selectors, XPath |
| `find_element_exercise_3.py` | Third location exercise | Advanced selectors, multiple elements |
| `filling_in_the_input_field.py` | Fill text fields | send_keys, input interaction |
| `click_on_an_element.py` | Click on elements | click(), buttons and links |
| `get_text.py` | Text extraction | get_attribute, text, innerHTML |
| `go_to_element.py` | Scroll and navigation | scroll_into_view, Actions |
| `open_and_close_page.py` | Browser management | get, quit, close |
| `practice_exercise_1.py` | Practice exercise 1 | Combination of basic skills |
| `practice_exercise_2.py` | Practice exercise 2 | Complete interaction flow |
| `practice_exercise_3.py` | Practice exercise 3 | More complex scenario |
| `connect_selenium_in_pycharm.py` | Environment setup | Selenium setup in PyCharm |

## Key decisions
- **Prioritized fundamental exercises** because they are the foundation for more complex automation
- **Focused on repetitive practice** to master Selenium commands before advancing to POM
- **Progression from simple to complex** to build confidence and skill gradually

## Results
- Mastery of element location with multiple selectors
- Ability to automate basic user interactions
- Solid foundation to advance to more complex frameworks (POM, testing frameworks)

## What would I improve next?
- Add assertions to validate results of each exercise
- Implement Page Object Model to refactor exercises
- Integrate with pytest or unittest for automated execution
- Add exercises with more complex elements (dropdowns, alerts, iframes)

# QA Python Tasks - Selenium Fundamentals

## ¿Que es esto?
Esta carpeta contiene ejercicios practicos de automatizacion web con Selenium y Python, disenados para dominar los fundamentos de la interaccion con elementos web.

## Producto / Funcionalidad bajo prueba
- Pagina web de practica para ejercicios de Selenium
- Elementos web basicos: input fields, botones, textos, navegacion

## Objetivo
Practicar y demostrar dominio de los comandos fundamentales de Selenium para automatizar interacciones con elementos web.

## Alcance
**Incluido:**
- Localizacion de elementos (find_element)
- Interacciones basicas: click, escribir en inputs, scroll
- Extraccion de textos de elementos
- Apertura y cierre de paginas
- Ejercicios practicos progresivos

**No incluido:**
- Page Object Model (POM)
- Aserciones avanzadas
- Framework de testing completo

## Artefactos en esta carpeta
| Archivo | Descripcion | Habilidad demostrada |
|---------|-------------|---------------------|
| `find_element_exercise_1.py` | Primer ejercicio de localizacion | Selenium find_element, selectores basicos |
| `find_element_exercise_2.py` | Segundo ejercicio de localizacion | Selectores CSS, XPath |
| `find_element_exercise_3.py` | Tercer ejercicio de localizacion | Selectores avanzados, multiple elements |
| `filling_in_the_input_field.py` | Completar campos de texto | send_keys, interaccion con inputs |
| `click_on_an_element.py` | Click en elementos | click(), botones y enlaces |
| `get_text.py` | Extraccion de textos | get_attribute, text, innerHTML |
| `go_to_element.py` | Scroll y navegacion | scroll_into_view, Actions |
| `open_and_close_page.py` | Gestion de navegador | get, quit, close |
| `practice_exercise_1.py` | Ejercicio practico 1 | Combinacion de habilidades basicas |
| `practice_exercise_2.py` | Ejercicio practico 2 | Flujo completo de interaccion |
| `practice_exercise_3.py` | Ejercicio practico 3 | Escenario mas complejo |
| `connect_selenium_in_pycharm.py` | Configuracion de entorno | Setup de Selenium en PyCharm |

## Decisiones clave
- **Priorice ejercicios fundamentales** porque son la base para automatizacion mas compleja
- **Enfoque en practica repetitiva** para dominar comandos de Selenium antes de avanzar a POM
- **Progresion de simple a complejo** para construir confianza y habilidad gradualmente

## Resultados
- Dominio de localizacion de elementos con multiples selectores
- Capacidad de automatizar interacciones basicas de usuario
- Base solida para avanzar a frameworks mas complejos (POM, testing frameworks)

## ¿Que mejoraria despues?
- Agregar aserciones para validar resultados de cada ejercicio
- Implementar Page Object Model para refactorizar ejercicios
- Integrar con pytest o unittest para ejecucion automatizada
